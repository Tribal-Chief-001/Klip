# Klip brand

One idea: **two devices joined by a line**. It is the logo, the launcher icon, the notification icon and the live
drawing on the Android home screen (a pulse runs along the line while the devices are connected).

| | |
|---|---|
| Ink (background) | `#0B0E10` (dark) · `#F3F4F0` (light, warm paper) |
| Signal (the only bright colour) | `#C8F25A` lime on dark · `#4D7A00` on light |
| Warning | `#FFB84D` dark · `#A85F00` light |
| Text | `#E8EDF0` on dark · `#12161A` on light; secondary `#8C979F` / `#5A646B` |
| Wordmark | lowercase **klip**, drawn from strokes (no font); the dot of the *i* is the signal colour |
| Shapes | 18 px cards with 1 px hairlines, no shadows; one filled button per screen |
| Tone | short, plain, honest. Say what it does, what it cannot see, and what is not verified |

Files in [`docs/assets`](assets): `logo-mark.svg/png` (app icon, 512 px), `wordmark.svg`, `banner.svg/png`
(README header), `social-preview.png` (1280 × 640, for GitHub's repository social preview).
Regenerate them all with `python3 docs/assets/make_assets.py` (needs Pillow).
